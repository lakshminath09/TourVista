# ✈️ TourVista – Explore India

**TourVista** is an Android travel application designed to help users explore destinations across India and plan their trips conveniently.

## 📱 About the Project

TourVista provides a simple and user-friendly platform for discovering popular tourist destinations, managing trips, and accessing useful travel-related information.

## ✨ Features

* 🔐 User Registration and Login
* 🔑 Forgot and Reset Password
* 🏠 Home Screen
* 🗺️ Explore Indian Tourist Destinations
* 📍 Place Details
* ❤️ Favorites
* 🧳 Plan and Manage Trips
* 👤 User Profile
* ⚙️ Settings
* ℹ️ About Us
* 🆘 Help and Support
* 🔒 Privacy Policy

## 🛠️ Technologies Used

* **Language:** Kotlin, Java
* **Platform:** Android
* **IDE:** Android Studio
* **UI:** XML
* **Build System:** Gradle

## 🚀 Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/lakshminath09/TourVista.git
   ```

2. Open **Android Studio**.

3. Select **Open** and choose the cloned `TourVista` folder.

4. Allow Gradle to sync.

5. Run the application on an Android emulator or a connected Android device.
